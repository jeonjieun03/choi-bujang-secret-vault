# 케셰브 완성본 시연 · 한계 · 근거 (학생 작성)

작전: 화면 틀 **관제 대시보드형**(맨 위 상태 카드 네 개, 아래 추이와 기록) · 포장 형태 **포장 없이 프로젝트 폴더에서 실행**(포장 명령은 실행하지 않음).

표시 규칙: **실측** = 학생 PC에서 실제로 잰 값 · **실제 실행** = 실제로 켜서 본 동작 · **모의 입력** = 학생 함수에 시험용 응답을 넣어 본 것 · **학생 진술** = 캡처 없이 학생이 말한 결과 · **예시** = 설명용 값 · **미확인** = 확인하지 못한 것.
이 문서에는 확인하지 않은 기능을 「된다」고 쓰지 않습니다.

## 2. 시연 순서 (약 3분, 핵심 기능 3가지)

준비: PowerShell에서 `cd $HOME\Documents\keshev\on-client` → `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1`, 브라우저 `http://127.0.0.1:5189/`. 작업 관리자(`Ctrl+Shift+Esc` → 성능)를 옆에 열어 둡니다.

| 순서 | 보여 줄 것 | 누를 곳 | 말할 것 |
|---|---|---|---|
| 0 | 첫 화면 | — | 위쪽 「연결 없음」과 빨간 안내는 회사 서버(SDP)에 연결하지 않고 켰기 때문이며 정상입니다. |
| 1 | **① 지금 상태** | 「보호 현황」 → 학생 상태 칸 「내 PC 조회」 | CPU·메모리·디스크·방화벽 카드에 잰 시각과 출처(이 PC 실측)가 붙습니다. 작업 관리자 메모리 값과 같습니다. CPU는 조회 순간 0.2초 값이라 더 높게 나올 수 있습니다. |
| 2 | **② 상태 추이** | 「다시 조회」 두 번(Tab → Enter로도 가능) | 지난 조회 대비 ▲▼ 변화와 추이 표가 한 줄씩 쌓입니다. |
| 3 | **③ 점검 기록 + 오류 화면** | PowerShell 창 `Ctrl+C` → 브라우저 「다시 조회」 | 빨간 안내에 원인(NETWORK_ERROR)·안 된 항목·다음에 할 일이 나오고, 지난 값은 현재 상태로 보여 주지 않습니다. 기록 맨 위에 「조회 실패」가 남습니다. |
| 4 | 회복 | 앱을 다시 켜고 「다시 조회」 | 오류 안내가 사라지고 새 실측이 기록됩니다. |
| 5 | 연결과 기록 | 대시보드 아래 표 | 네트워크 구성·방화벽·Windows 경고·오류는 읽기만 하며, 건수는 침해 판정이 아닙니다. 맨 아래 SDP 서버 줄은 「SDP 미연결」로 PC 조회와 따로 표시합니다. |

시연 중 막히는 기능은 숨기지 않고 3장 한계로 말합니다.

## 3. 한계 (아직 안 되거나 「확인 불가」로 남은 것)

| 항목 | 상태 | 이유 |
|---|---|---|
| 로그인 사용자·기기·세션, 업무 앱 판정, 보안 기록 | 기본 실행에서 「연결 없음」, 예제 실행에서만 예시 값 | 회사 접근 제어 서버(SDP) 연결 설정은 담당자가 준비하는 것이며 받지 않음 |
| 앱 안 AI 연결 점검·AI 사건 설명 | 「권한 준비 중(ON_AI_PROVISIONING_PENDING)」 | 학생 계정의 앱 권한 발급 전. 17단계 피드백에서도 실제 설명 호출(`ai_model_called`)은 확인 보류 |
| 실제 보안 조치 집행·효과 확인 | 지원 안 됨 | 조치 연동 시스템 미연결, 기록의 지원 조치 목록이 비어 있음 |
| 설치 패키지 취약점 조회 | 「조회 준비 미완료(not_configured)」 | 조회 대상 프로젝트·승인 목록은 담당자가 준비 |
| CPU 값 | 작업 관리자와 다를 수 있음 | 조회 순간 0.2초 표본 + 같은 순간 방화벽·기록 조회 실행(제공 코드 구조) |
| ② 추이·③ 기록 | 저장하지 않음 | 화면 메모리에만 둠. 새로 고치면 지워짐 |
| Windows 경고·오류 건수, 방화벽 「켜짐」, 「정상(기준 이내)」 | 판정 아님 | 관찰 값일 뿐 침해·안전 판정이 아님 |
| 네트워크 구성 | 로컬 요약 | 인터넷 접속이나 ZTNA 허용을 확인한 결과가 아님 |
| 포장(`npm run package-app`)·설치 프로그램 | 하지 않음 | 이번 과정 범위 밖 |
| 다른 사람 PC에서의 실행 | 학생 진술만 있음 | 5일차 재실행은 캡처 없이 학생 진술로 기록 |

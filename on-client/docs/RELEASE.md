## 누락·미해결 사항

1. 17단계 `ai_model_called` 확인 보류: 담당자의 앱 권한 발급 뒤 실제 설명 요청이 필요합니다.
2. 19단계 실제 집행: 운영 측 조치 연동 시스템 연결이 필요합니다(학생이 운영자 권한을 받거나 집행기를 만들지 않음).
3. 학생 PC(Windows)에서의 직접 재현 기록이 없습니다.
